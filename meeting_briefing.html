매일 아침 발생하는 대용량 GS EDI 발주(1편, 본발주, 슈퍼) 및 미출 내역의 수기 복사·붙여넣기 업무를 전면 전산화하여, 파일 업로드 한 번으로 "수주 취합 → 자재 소요량(BOM) 전개 → 생산라인 작업지시 → 최종 매출 확정"까지 5초 만에 완료되는 원스톱 파이프라인을 구축했습니다.

1. 기존 수작업 한계 vs 스마트 ERP 개선 비교
구분 기존 수작업 프로세스 신규 스마트 ERP 도입 후
수주 데이터 취합 1편, 본발주, 슈퍼 엑셀을 각각 열어 점포/센터별로 수기 집계 (일 60~90분 소요) 상단 [엑셀 수주 GS25] 버튼 클릭 후 드롭 시 3초 만에 통합 적재
미출(결품) 정산 2줄 1쌍의 복잡한 미출 엑셀을 수기로 대조하여 오차 및 누락 빈번 발생 미출 전용 파서가 센터별 결품량 자동 차감 → 최종 확정금액 실시간 산출
자재 발주 소요량 수주량을 바탕으로 계산기 두드려 쌀, 김, 소스, 포장재 발주서 수기 작성 등록된 BOM(배합비) 기준으로 원부자재 일일 필요 발주량 즉시 자동 계산
현장 작업지시 생산 라인별(김밥, 삼각김밥, 도시락, 샌드) 작업 수량을 전화/메모로 전달 수주 확정 즉시 라인별 제조 작업지시서가 시스템에 자동 생성 및 공유
2. 매일 수신되는 GS리테일 EDI 4대 데이터 완벽 지원

담당자: 전산 및 프로세스 구축 담당
상태: 정식 배포 완료 (실서버 즉시 사용 가능)
3. 원클릭 파일 업로드 후 즉시 확인 가능한 5대 화면
1. 미출현황 화면

위치: [영업관리] > [미출현황]
센터별(김포, 오산, 남양주 등) 및 품목별 결품 수량, 미출 금액, 미출 사유 실시간 통계 표출

2. 가매출/확정금액 현황

위치: [경영기획] > [가매출/미출/확정금액]
가매출액 - 미출액 = 최종 확정매출액 공식이 일자별·센터별로 자동 연산되어 표출

3. 종합 대시보드

위치: [홈] 메인 대시보드
오늘 총 주문금액, 납품 달성률, 주력 라인 가동 지표를 실시간 통합 게이지로 모니터링

4. 일일 자재발주 (BOM 전개)

위치: [구매자재] > [일일 자재발주]
수주된 김밥, 삼각김밥, 도시락 수량을 기준으로 쌀, 김, 소스, 필름 등 원부자재 소요량을 역산하여 발주서 생성

5. 공정별 작업지시서

위치: [생산관리] > [작업지시서]
김밥 1호 라인, 삼각김밥 라인, 도시락 라인, 샌드위치 라인, 취반기 등 각 공정별 필요 생산 수량이 자동 배분

4. 오후 3시 라이브 시연 순서 (총 5분 소요)
1
웹사이트 접속
gfserp.vercel.app 로그인 후 메인 대시보드 진입
2
엑셀 파일 드롭
상단 [엑셀 수주 GS25] 버튼 클릭 → 엑셀 파일 마우스 드롭
3
원클릭 실시간 반영
[데이터 즉시 반영] 클릭 즉시 5대 화면에 모든 데이터 자동 분배
